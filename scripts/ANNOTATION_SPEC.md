# Спецификация разметки задач

Вход: `raw/batches/NN.json` — массив задач `{id, olympiad, year, grade, num, statement, matol_comments[]}`.
`matol_comments` — комментарии пользователей matol.kz (часто содержат решения, иногда неверные или неполные).

Выход: `annotations/NN.json` — JSON-массив (UTF-8, валидный JSON, `ensure_ascii=False`), по одному объекту на КАЖДУЮ задачу батча, в том же порядке:

```json
{
  "id": "m97-1",
  "topic": "algebra | combinatorics | geometry | number_theory",
  "subtopics": ["неравенства", "..."],
  "difficulty": 4,
  "skills": [{"name": "Неравенство о средних (AM-GM)", "note": "применяется к парам a·(a,b) и b·[a,b]"}],
  "hints": ["подсказка 1 (самая мягкая)", "подсказка 2", "подсказка 3 (почти решение)"],
  "solution": "полное решение, Markdown + LaTeX в $...$ / $$...$$",
  "answer": "краткий ответ или null, если задача на доказательство",
  "solution_source": "matol | ai | none",
  "confidence": "high | medium | low"
}
```

## ГЛАВНОЕ ПРАВИЛО О РЕШЕНИЯХ (приоритет над пунктами 5–6 ниже)

- **Есть решение в `matol_comments`** (в любой олимпиаде): сам задачу НЕ решай. Прочитай решение, пойми его, перепиши аккуратно и кратко; `solution_source = "matol"`. Skills и hints строй по этому решению. Если решение в комментариях явно неверное или обрывочное и ты его не понимаешь — не придумывай своё, поставь `solution = ""`, `solution_source = "none"`.
- **Решения нет, олимпиада «Республиканская олимпиада, областной этап»**: реши сам, `solution_source = "ai"`, честный `confidence`.
- **Решения нет, любая другая олимпиада** (заключительный этап респы, Жаутыковская, Шелковый путь, АТМО, BMO, JBMO): задачу НЕ решай. Заполни только `topic`, `subtopics`, `difficulty`; `skills = []`, `hints = []`, `solution = ""`, `answer = null`, `solution_source = "none"`, `confidence = "low"`.
- Геометрия — по-прежнему только topic/subtopics/difficulty (пункт 5).

## Правила

1. **Язык** — русский. Формулы — LaTeX в `$...$` (inline) и `$$...$$` (display). В JSON экранируй обратные слэши (`\\frac`). Не используй `\[ \]` и `\( \)`.
2. **topic** — ровно одна основная тема. Задачи «на доске/игры/графы/алгоритмы/оценка+пример» — combinatorics. Функциональные уравнения, неравенства, многочлены, последовательности — algebra. Делимость, простые, диофантовы — number_theory.
3. **subtopics** — 1–4 короткие подтемы на русском из естественного словаря олимпиадника (например: «неравенства», «функциональные уравнения», «многочлены», «последовательности», «графы», «инварианты», «раскраски», «игры», «экстремальный принцип», «диофантовы уравнения», «сравнения по модулю», «счёт двумя способами», «вписанные четырёхугольники», «подобие», «вычисления в геометрии» и т.п.). Используй одинаковые формулировки для одинаковых понятий.
4. **difficulty** 1–10, единая шкала для всех олимпиад:
   - 1–2: лёгкие задачи областного этапа (№1–2 9 класса);
   - 3–4: средние задачи областного, лёгкие заключительного; JBMO №1;
   - 5–6: средние/трудные заключительного этапа, Жаутыковская №1/№4, BMO №1, Шёлковый путь №1, APMO №1–2;
   - 7–8: трудные задачи Жаутыковской, BMO, APMO, Шёлкового пути;
   - 9–10: самые трудные задачи (уровень IMO №3/№6).
5. **ГЕОМЕТРИЯ (topic = geometry)**: заполни только `topic`, `subtopics`, `difficulty`. Поля `skills` = [], `hints` = [], `solution` = "", `answer` = null, `solution_source` = "none", `confidence` = "low". Геометрию НЕ решай.
6. **Остальные темы** — заполни всё:
   - `skills`: 2–6 теорем/лемм/приёмов, реально нужных для решения, каждая с короткой заметкой `note`, КАК она применяется именно здесь (одно предложение, без раскрытия всего решения).
   - `hints`: 2–3 постепенные подсказки, от общей идеи к ключевому шагу.
   - `solution`: полное строгое решение, понятное школьнику-олимпиаднику. Абзацы разделяй пустой строкой.
   - Если в `matol_comments` есть верное решение — проверь его, исправь пробелы и перепиши аккуратно своими словами; `solution_source = "matol"`. Если решения там нет или оно неверно/неполно — реши сам; `solution_source = "ai"`.
   - **Честность важнее полноты.** `confidence`: high — уверен, что решение верное и полное; medium — основная идея верна, но есть места, которые стоит перепроверить; low — не смог полностью решить. При low так и напиши в начале решения: «⚠️ Решение неполное: …» и опиши, что доказано, а что нет. Никогда не выдавай неверное рассуждение за полное.
   - Если задача требует ответа (найти, вычислить) — заполни `answer`.
7. Пиши файл целиком в конце батча (или постепенно, но в итоге — валидный JSON-массив со всеми id батча). Проверь валидность: `python3 -c "import json;json.load(open('annotations/NN.json'))"` и что количество объектов совпадает с батчем.
