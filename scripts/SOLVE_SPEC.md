# Решение задач без решения

Вход: `raw/solve_batches/sNN.json` — массив задач `{id, olympiad, year, grade, num, statement, matol_comments, topic, subtopics, difficulty}`.
Выход: `solve/sNN.json` — JSON-объект `{ "<id>": {...} }` по ВСЕМ id батча:

```json
{
  "skills": [{"name": "Теорема Птолемея", "note": "как применяется здесь"}],
  "hints": ["мягкая подсказка", "вторая", "третья — почти решение"],
  "solution": "полное решение, Markdown + LaTeX в $...$ / $$...$$",
  "answer": "краткий ответ или null",
  "insight": "3–6 предложений: как можно было догадаться до этой идеи",
  "confidence": "high | medium | low"
}
```

Правила:
1. Реши задачу по-настоящему, строго и полностью. Русский язык. Абзацы — через пустую строку.
2. `matol_comments` — обсуждение с сайта (идеи, ответы, иногда ошибки). Можешь опираться, но проверяй.
3. **Проверяй себя вычислениями**: у тебя есть Python (`python3`). Для задач «найти все…» — перебор малых случаев; для неравенств — случайные проверки; для геометрии — численная проверка утверждения на случайной конфигурации (координаты/комплексные числа). Не выдавай непроверенный ответ за точный.
4. Геометрия: подходят синтетика, координаты, комплексные числа, барицентрические координаты, тригонометрия. Если в условии есть «[рисунок: url]» — опиши, что из рисунка следует, по тексту условия.
5. **Честность важнее полноты.** `confidence`: high — уверен в полном и верном решении (и проверил численно, где это возможно); medium — идея верна, но есть места для перепроверки; low — решение неполное: начни текст с «⚠️ Решение неполное: …» и чётко скажи, что доказано, а что нет. Никогда не выдавай дырявое рассуждение за полное.
6. Если условие обрезано или непонятно — восстанови по смыслу/комментариям и явно напиши об этом в начале решения, confidence не выше medium.
7. Записывай файл батча сразу после готовности. Валидный JSON, UTF-8, `ensure_ascii=False`. Не трогай другие файлы.
