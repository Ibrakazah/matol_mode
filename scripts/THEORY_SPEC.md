# Спецификация конспектов (блок «Теория»)

Список тем: `/home/user/matol_mod/scripts/theory_topics.json` (id, area, title). Для каждой темы напиши файл
`/home/user/matol_mod/theory_notes/<id>.md` (Markdown + LaTeX в `$...$` / `$$...$$`, русский язык).

Структура файла (заголовки именно такие):

```
## Идея
2–4 предложения: о чём тема и зачем она нужна на олимпиаде.

## Основные факты
Нумерованный список: формулировки теорем/лемм/приёмов. К самым важным — краткое доказательство или набросок (1–4 строки).

## Как догадаться, что это применять
Маркированный список «признаков»: по каким внешним сигналам в условии видно, что нужен этот приём
(например: «в условии симметричная сумма и условие $abc=1$ → подумай про AM-GM или подстановку»).
Опиши ход мысли: что пробуешь сначала, что делаешь, если не получилось.

## Типичные ошибки
2–4 пункта.

## Примеры из базы
Для 3–5 задач из этой темы, от лёгкой к сложной: `[id задачи]` — одна строка, как тема применяется именно там.
Список задач темы и их сложность смотри в /home/user/matol_mod/public/data/theory.json (поле problems; has_sol=true означает, что у задачи есть решение).
Условие задачи с id mOID-NUM лежит в /home/user/matol_mod/public/data/index.json (поле st), решение — в public/data/o/OID.json по ключу id.
Бери примеры ТОЛЬКО среди задач с has_sol=true и только те, решение которых ты прочитал и понял. Ссылайся на задачу в виде `[[id]]`, например `[[m97-2]]`.
```

Требования: пиши по существу и корректно, только проверенные математические факты (классические теоремы); не выдумывай ссылок и авторов. Длина — 250–600 слов на тему. Не трогай никакие файлы, кроме `theory_notes/<id>.md`.
