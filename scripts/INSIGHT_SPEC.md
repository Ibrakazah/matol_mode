# Спецификация блока «Как догадаться»

Вход: `/home/user/matol_mod/raw/insight_batches/NN.json` — массив `{id, statement, skills, hints, solution}`.
Выход: `/home/user/matol_mod/insights/NN.json` — JSON-объект `{ "<id>": "<текст>" }` по всем id батча (валидный JSON, UTF-8, `ensure_ascii=False`).

Для каждой задачи напиши 3–6 предложений на русском (Markdown + LaTeX в `$...$`): **как можно было прийти к этому решению сам**, а не пересказ решения.
Опиши ход мысли: что в условии бросается в глаза, какие простые эксперименты (малые случаи, подстановки) наводят на идею, почему естественно пробовать именно этот приём, на каком шаге часто застревают.
Опирайся только на решение из файла — ничего не придумывай и не добавляй новых математических утверждений. Не пересказывай решение целиком и не выдавай финальный ответ.
Не трогай другие файлы.
