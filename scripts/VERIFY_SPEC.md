# Проверка решений

Вход: файл разметки `annotations/X.json` (массив задач) и файл с условиями `raw/batches/X.json`
(для X = 00..39) или `raw/batches_old/X.json` (для X = o00..o31). Совпадение по полю `id`.
В файле условий есть `statement` и `matol_comments`.

Проверяй ТОЛЬКО задачи, у которых непустое поле `solution`.

Для каждой такой задачи:
1. Прочитай условие и решение. Проверь каждый шаг: верны ли утверждения, нет ли пропусков, соответствует ли ответ условию.
   Если в `matol_comments` есть решение — сверь ответ с ним.
2. Вынеси вердикт:
   - `ok` — решение верное и полное;
   - `fixed` — были ошибки/пробелы, и ты их исправил: дай исправленное полное решение в `solution` (и `answer`, если ответ изменился);
   - `wrong` — решение неверное и исправить не получилось;
   - `unsure` — не можешь уверенно проверить.
3. `note` — одно предложение: что не так / что исправлено (для ok можно пусто).

Выход: `verify/X.json` — JSON-объект `{ "<id>": {"verdict": "...", "note": "...", "solution": "...", "answer": "..."} }`
(`solution`/`answer` — только при `fixed`). Markdown + LaTeX в `$...$`, русский язык. Валидный JSON, `ensure_ascii=False`.
Не меняй никакие другие файлы. Будь строг: «ok» только если реально проверил каждый шаг.
