# Полная разметка и решение задачи (один проход)

Вход: `raw/full_batches/XNNN.json` — массив `{id, olympiad, title, year, grade, num, statement, matol_comments[]}`.
Выход: `annotations/XNNN.json` — JSON-массив, по одному объекту на КАЖДУЮ задачу батча, в том же порядке:

```json
{
  "id": "m123-4",
  "topic": "algebra | combinatorics | geometry | number_theory",
  "subtopics": ["неравенства"],
  "difficulty": 4,
  "skills": [{"name": "Неравенство о средних (AM-GM)", "note": "как применяется именно здесь"}],
  "hints": ["мягкая подсказка", "вторая", "третья — почти решение"],
  "solution": "полное решение, Markdown + LaTeX в $...$ / $$...$$",
  "answer": "краткий ответ или null",
  "insight": "3–6 предложений: как можно было самому догадаться до идеи решения",
  "solution_source": "matol | ai",
  "confidence": "high | medium | low"
}
```

## Правила
1. Русский язык. LaTeX: `$...$` и `$$...$$` (не `\[ \]`). В JSON экранируй обратные слэши. Абзацы — через пустую строку.
2. **topic** — одна основная тема (игры/графы/оценка+пример/алгоритмы — combinatorics; неравенства, функциональные уравнения, многочлены, последовательности — algebra; делимость, простые, диофантовы — number_theory). **subtopics** — 1–4 короткие подтемы из привычного словаря олимпиадника («неравенства», «сравнения по модулю», «вписанные четырёхугольники», «инварианты», «графы», «игры», «степень точки», …).
3. **difficulty** 1–10, единая шкала: 1–2 — лёгкие задачи районного этапа и олимпиад 6–7 классов; 3–4 — средние районного/областного, лёгкие Эйлера и юниорской; 5–6 — заключительный этап, трудные Эйлера, Туймаада/ЕГМО №1; 7–8 — трудные задачи Туймаады, ЕГМО, Западно-Китайской, IMO №1/4; 9–10 — IMO №2/5 и выше, самые трудные №3/6.
4. **Решение:**
   - если в `matol_comments` есть верное решение — пойми его, проверь, перепиши аккуратно и полно своими словами; `solution_source = "matol"`;
   - иначе реши сам; `solution_source = "ai"`.
   Решения пишутся для ВСЕХ задач, включая геометрию.
5. **Проверяй себя на Python** (`python3`): перебор малых случаев для «найдите все»; случайные проверки неравенств; численная проверка геометрии на случайной конфигурации (координаты/комплексные числа).
6. **skills** — 2–6 реально нужных теорем/приёмов с заметкой `note`, как именно они применяются здесь. **hints** — 2–3 постепенные подсказки. **answer** — если задача на «найти/вычислить».
7. **Честность важнее полноты.** `confidence`: high — уверен в полном верном решении (и проверил численно, где можно); medium — идея верна, есть места для перепроверки; low — неполное: начни решение с «⚠️ Решение неполное: …» и скажи, что доказано, а что нет. Если условие обрезано/с опечаткой — восстанови по смыслу, напиши об этом в начале решения, confidence не выше medium.
8. Записывай файл батча сразу после готовности; валидный JSON, `ensure_ascii=False`, все id батча в том же порядке. Если выходной файл уже существует и валиден — пропусти батч. Не трогай другие файлы.
