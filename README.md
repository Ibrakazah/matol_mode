# matol mod

Личная копия задач по математике с [matol.kz](https://matol.kz) с дополнениями:

- тема, подтемы и сложность (1–10) у каждой задачи;
- скрытые блоки (нажми, чтобы открыть): нужные теоремы и приёмы, подсказки по шагам, решение;
- фильтры: тема, подтема, сложность, олимпиада, год, класс, теорема, поиск по условию;
- отметки «решена» / «избранное» (хранятся в браузере).

Все олимпиады раздела «Математика» matol.kz: Республиканская (районный, областной, заключительный этапы, юниорская), Эйлера, Шелковый путь, АТМО, Иранская по геометрии, IMO, Жаутыковская, Туймаада, BMO, JBMO, Западно-Китайская, EGMO, EMO, городские (Алматы, Жаутыковская, Аль-Фараби, Смагулова).

Также как на matol: дерево олимпиад, условия на казахском (переключатель «Рус/Қаз»), страницы «комментарий/решение», авторы задач, новости и объявления, информация об олимпиадах, книги, рейтинг, последние обсуждения, печать олимпиады. Плюс личные заметки к задачам.
Решения: переписанные с matol (пометка «matol») и написанные ИИ (пометка «ИИ», с уровнем уверенности). Все решения прошли автоматическую проверку.

## Устройство

Статический сайт, папка `public/` (деплоится на Vercel как есть).

- `scripts/crawl_tree.py` → `raw/tree.json` (дерево разделов matol), `scripts/scrape_full.py` → `raw/olympiads_full.json` (все олимпиады, русский и казахский, комментарии), `scripts/scrape_pages.py` → `raw/pages.json` (инфо, новости, книги).
- `scripts/FULL_SPEC.md`, `scripts/make_full_batches.py` — разметка и решение новых задач одним проходом.
- `scripts/make_batches.py` — режет задачи на батчи для разметки (`raw/batches/`).
- `scripts/ANNOTATION_SPEC.md` — формат разметки; результаты лежат в `annotations/`.
- `scripts/apply_verify.py` — вливает итоги проверки решений (`verify/`).
- `scripts/make_solve_batches.py`, `scripts/SOLVE_SPEC.md`, `scripts/apply_solve.py` — решения для задач без решения (`solve/`).
- `scripts/build_data.py` — собирает `public/data/` из `raw/`, `annotations/` и `insights/`; `scripts/build_theory.py` — блок «Теория».

Локально: `python3 scripts/build_data.py && cd public && python3 -m http.server`.
