## Идея
Китайская теорема об остатках (КТО) говорит, что система сравнений с попарно взаимно простыми модулями всегда разрешима и её решение единственно по модулю произведения. На практике она используется в двух направлениях: собрать решение из остатков по отдельным модулям и, наоборот, разбить проверку делимости или сравнения по составному модулю на проверки по степеням простых. Второе направление важнее на олимпиаде: оно позволяет решать задачи, где сразу понять поведение по большому модулю нельзя.

## Основные факты
1. КТО: если $m_1,\dots,m_k$ попарно взаимно просты, то система $x\equiv a_i\pmod{m_i}$ имеет решение, единственное по модулю $m_1m_2\cdots m_k$.
2. Для двух модулей без условия взаимной простоты: система $x\equiv a\pmod m$, $x\equiv b\pmod n$ разрешима тогда и только тогда, когда $a\equiv b\pmod{\gcd(m,n)}$. Решения образуют класс по модулю $\operatorname{lcm}(m,n)$.
3. Проверка делимости: если $N=\prod q_i^{e_i}$, то $N\mid X$ тогда и только тогда, когда $q_i^{e_i}\mid X$ для всех $i$. Поэтому делимость на составной модуль проверяется по каждой степени простого отдельно.
4. Аналогично для сравнений: $X\equiv Y\pmod N$ равносильно набору сравнений по всем $q_i^{e_i}$.
5. Периодичность: если $d_1$ и $d_2$ — периоды функции, заданной на классах вычетов, то и $\gcd(d_1,d_2)$ — период (это проверяется через разрешимость системы из факта 2).

## Как догадаться, что это применять
- Нужно доказать делимость на большое составное число, например $(p)!$ или $2^k\cdot3^m$. Разложи модуль на степени простых и докажи делимость по каждой степени.
- Требуется построить число с заданными остатками по нескольким модулям. Используй КТО и проверь совместность через $\gcd$ модулей.
- Задача о периодах функции или последовательности: периоды $d_1$ и $d_2$ дают систему сравнений, и разрешимость по $\gcd$ даёт новый период.
- Ход мысли: разложи модуль, для каждой степени простого найди нужное сравнение (например через Эйлера или Ферма), затем собери результат; если модули не взаимно просты, сначала проверь условие на $\gcd$.

## Типичные ошибки
- Применять КТО к модулям, которые не взаимно просты, без проверки условия $a\equiv b\pmod{\gcd}$.
- Считать, что решение единственно по каждому модулю отдельно; оно единственно только по произведению (или по $\operatorname{lcm}$).
- При разложении модуля на степени забыть одну из степеней, особенно если простое входит с кратностью больше 1.
- Проверять делимость на $q$, а не на $q^e$, и делать вывод о делимости на $q^e$.

## Примеры из базы
- [[m502-2]] (уровень 3): $p!=\prod q^{e_q}$; для каждого $q^e$ по теореме Эйлера $a^{(p-1)!}\equiv1$, и КТО собирает делимость на $p!$.
- [[m886-5]] (уровень 6): лемма о периодах: система $Y\equiv a\pmod{d_1}$, $Y\equiv b\pmod{d_2}$ разрешима, так как $a\equiv b\pmod{\gcd(d_1,d_2)}$; отсюда $\gcd(d_1,d_2)$ тоже период.
