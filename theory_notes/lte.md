## Идея
Показатель вхождения простого $p$ в число $v_p(n)$ — наибольшая степень $p$, делящая $n$. Лемма о поднятии показателя (LTE, Lifting The Exponent) даёт точную формулу для $v_p(x^n\pm y^n)$ при условии $p\mid x\mp y$. Это позволяет превратить сложное условие делимости в линейное сравнение показателей. Приём часто нужен в задачах с суммами и разностями степеней, например $2^a+3^b$, и в задачах на делимость $(abc)^n\mid\dots$.

## Основные факты
1. LTE для нечётного простого $p$: если $p\mid x-y$ и $p\nmid xy$, то $v_p(x^n-y^n)=v_p(x-y)+v_p(n)$ для любого натурального $n$.
2. LTE для суммы: если $n$ нечётно, $p\mid x+y$, $p\nmid xy$, то $v_p(x^n+y^n)=v_p(x+y)+v_p(n)$.
3. Случай $p=2$: если $x,y$ нечётны и $n$ нечётно, то $v_2(x^n-y^n)=v_2(x-y)$. Если $n$ чётно, то $v_2(x^n-y^n)=v_2(x-y)+v_2(x+y)+v_2(n)-1$.
4. Формула Лежандра: $v_p(n!)=\sum_{i\ge1}\lfloor n/p^i\rfloor$.
5. Для произведения и НОК: $v_p(ab)=v_p(a)+v_p(b)$, $v_p(\operatorname{lcm}(a,b))=\max(v_p(a),v_p(b))$, $v_p(\gcd(a,b))=\min(v_p(a),v_p(b))$.
6. Делимость $A\mid B$ равносильна $v_p(A)\le v_p(B)$ для всех простых $p$. Это главный способ сравнивать степени.

## Как догадаться, что это применять
- В условии есть $x^n\pm y^n$ с переменным показателем, и требуется делимость на степень простого. Выбери простое $p$, проверь условие $p\mid x\mp y$ и примени LTE.
- В уравнении $2^a+3^b=5^c d$ правая часть содержит степень простого $5$. Посчитай $v_5$ левой части через LTE, и это ограничивает $c$ и $a$.
- Задача на делимость $(abc)^n\mid E$ для всех $n$. Сравни $v_p$ обеих сторон для каждого простого $p$, это даёт неравенство между показателями.
- Задача с НОК и произведением: $L\mid bc$ проверяется через $v_p$ для каждого простого.
- Ход мысли: выбери простое $p$, определи его вхождения в левую и правую части, сравни показатели; если $p$ делит разность или сумму, применяй LTE; для $p=2$ отдельно проверяй чётность.

## Типичные ошибки
- Применять LTE без условий $p\mid x-y$ и $p\nmid xy$; без них формула неверна.
- Забыть особый случай $p=2$: там формула для чётного показателя другая.
- Путать $v_p(n)$ (показатель самого $n$) с показателем степени в LTE.
- Сравнивать $v_p$ только для одного простого и делать вывод о делимости всего числа.

## Примеры из базы
- [[m1055-6]] (уровень 4): из неравенства $5L=ab+bc+ca\ge3bc$ и сравнения $v_p$ получается $L\mid bc$, что позволяет найти $L=bc$.
- [[m152-2]] (уровень 5): условие $(abc)^n\mid E^3$ для всех $n$ переписывается через $v_p$ для каждого простого $p$, и это даёт совпадение простых делителей $a,b,c$.
- [[m1153-1]] (уровень 6): по LTE $v_5(2^a+3^a)=1+v_5(a)$ (после подходящего преобразования), и сравнение показателя с $c$ ограничивает $a$.
